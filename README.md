# HR Analytics Dashboard | Excel

## Project Overview
This project focuses on analyzing Human Resources (HR) data using Microsoft Excel to understand employee demographics, department distribution, salaries, job ratings, and attendance-related metrics.

The main goal is to transform raw employee data into meaningful insights that help HR teams monitor workforce distribution, compensation, and employee-related indicators.

## Dataset Description
The dataset contains **689 employee records and 15 columns**.

Each row represents one employee, and the dataset includes the following information:

| Column | Description |
|---|---|
| ID | Unique employee identifier |
| First Name | Employee's first name |
| Last Name | Employee's last name |
| Gender | Employee's gender |
| Start Date | Employee's joining date |
| Years | Years of service |
| Department | Employee's department |
| Country | Country where the employee works |
| Center | Employee's work center |
| Monthly Salary | Monthly salary |
| Annual Salary | Annual salary |
| Job Rate | Employee's job rating |
| Sick Leaves | Number of sick leave days |
| Unpaid Leaves | Number of unpaid leave days |
| Overtime Hours | Number of overtime hours |

## Project Workflow

### 1. Data Understanding
- Reviewed the employee dataset and its structure.
- Identified the available columns and their data types.
- Explored employee information, salaries, departments, and attendance metrics.

### 2. Data Quality Checks
- Checked for missing values.
- Checked for duplicate records.
- Reviewed data types to ensure that dates and numerical fields could be analyzed correctly.

The reviewed dataset contained no missing values or fully duplicated rows.

### 3. Data Analysis Using Pivot Tables
Created Pivot Tables to summarize the data and analyze different HR metrics.

The analysis included:

- **Employee Demographics:** Employee count by gender.
- **Department Analysis:** Number of employees in each department.
- **Geographical Analysis:** Employee distribution by country.
- **Work Center Analysis:** Employee count across different centers.
- **Salary Analysis:** Total and average monthly and annual salaries.
- **Attendance Analysis:** Sick leaves, unpaid leaves, and overtime hours.
- **Job Rating Analysis:** Distribution of employees across job rating levels.

### 4. KPI Analysis
Calculated and summarized key HR metrics, including:

- Total number of employees.
- Total monthly and annual salary expenses.
- Average monthly and annual salary.
- Total sick leave days.
- Total unpaid leave days.
- Total overtime hours.
- Employee distribution by gender, department, country, and center.

### 5. Dashboard Development
Used Excel Pivot Tables and visual summaries to organize the results into an HR dashboard.

The dashboard helps users explore workforce data and understand important HR indicators in a clear and organized way.

## Key Findings

- The dataset contains **689 employees**.
- Male employees account for 449 employees, while female employees account for 240 employees.
- Manufacturing is the largest department, with 140 employees.
- Egypt has the highest number of employees, with 379 employees.
- The Main work center has the largest workforce, with 251 employees.
- The average monthly salary is approximately 2,068.
- The average annual salary is approximately 24,818.
- Total recorded overtime is 9,441 hours.
- Total sick leave records amount to 1,109 days.
- Total unpaid leave records amount to 523 days.

*Note: Salary figures are reported in the dataset's original units. The findings describe this dataset and should not be interpreted as company-wide facts beyond its scope.*

- Analyze attendance and overtime patterns.
